OW_BILLING access-pattern evidence
==================================

This file records observed reads, writes, joins, and transaction boundaries
only. It does not propose a target collection model or mapping.

---------------------------------

Cross-cutting observed traps
----------------------------

The estate contains separate bulk feed tables INVOICE_HEADER/INVOICE_LINE and
transactional package tables INVOICES/INVOICE_LINES. The runtime reports use
the bulk pair; the PL/SQL invoicing package uses the transactional pair.

ENTITY_ATTR_VALUE is populated by the fixture and has string ATTR_VALUE and
string CREATED_DT fields, but no inspected runtime report query or OW_BILLING
package source references it.

CUSTOMER_MASTER has 155 columns. The schema includes repeated/comma-separated
fields and VARCHAR2 date fields; CUSTOMER_MASTER_HIST is maintained by a
full-row history trigger. SUBSCRIPTIONS_HIST.HIST_DT is also a string.

Explicit NLS handling is present in PKG_OW_UTIL date conversion and
PKG_DUNNING day-name conversion. The static seed sets session
NLS_DATE_FORMAT and NLS_TIMESTAMP_FORMAT. Date filtering in rating and dunning
uses formatted strings rather than direct date predicates.

The all_source ROWID search returned no rows. Broad exception handling is
present in PKG_OW_UTIL.f_str2dt, PKG_PLANS.fn_entitlement,
PKG_DUNNING.sp_schedule_dunning, and the audit purge scheduler block.
