# U4 contract — rating (decision-first)

Unit U4, wave 2, class proc-heavy. Content below is the approved mapping-spec v1.1
contract for the rating tables. Nothing here amends the approved mapping.

- Mapping: `.migration/03_mapping_spec.{md,json}` v1.1 (APPROVED)
- Tolerances: `.migration/02_tolerances.{md,json}` v1.0 (APPROVED, STOP A)
- Canonicalization: `.migration/recon_canonicalization.json` v1.1
- Target db: `ow_tp_mongodb_032752`; every document carries `ns: "mongo_032752"`.
- Registered write targets: `ow.usage_events`, `ow.rating_periods`,
  `ow.rating_results`. These targets have no collision with another unit.
- The unit has no embeds, so there is no UNGRADED-embed risk.

reconciliation harness. Oracle is read-only after fixture seeding.

## Type contract applied to this unit

| Oracle | Columns here | BSON | Canonicalization |
|---|---|---|---|
| VARCHAR2 | `tenant_id`, `period_id`, `subscription_id` | string | `empty_string_is_null` |
| TIMESTAMP(6), DATE | `occurred_at`, `period_start`, `period_end`, `created_at` | date | UTC, truncate to milliseconds |
| NUMBER(10,0), NUMBER(4,0) | `units`, `used_units`, `quota_units`, `rollover_units`, `billable_units`, `kind_cd` | Int64 for units fields; int for `kind_cd` | — |
| NUMBER(12,2) | `overage_amount` | Decimal128 | decimal round, half-even |

Source NULL becomes an explicit BSON null; NULL is not missing. The loader
preserves the approved mapping types and does not write to `subscriptions`,
which is a read-only U3-owned collection for the service seam.

## Index plan

- `usage_events`: `(tenant_id, occurred_at, kind_cd)`
- `rating_results`: `(period_id)`
- `rating_periods`: `_id` only (implicit)

`uq_rating_periods` on `(tenant_id, period_start)` and `fk_rr_period` from
`rating_results.period_id` to `rating_periods._id` are enforced application-side
inside the finalize transaction. The approved mapping index plan defines no
unique/natural-key index on `rating_periods`, so U4 does not add one. No other
collection or database is written by U4. No embeds are used.

## Stored-procedure replacement

| Source object | Replacement |
|---|---|
| `compute_rating` | `RatingService.compute_rating` |
| `fn_usage_rating` | `RatingService.compute_rating` returning `Rating` |
| `fn_usage_summary` | `RatingService.usage_summary` |
| `sp_finalize_rating` | `RatingService.finalize_rating` |
| `trg_usage_events_check` | `RatingService.insert_usage_event` |

The application port preserves the source's day-granularity `TO_CHAR` window
comparison, the `LEAST/NVL` double rollover cap, the 101-unit tier break,
`GREATEST(quota-used,0)` stored rollover, insert-then-update upsert behavior,
and Oracle `ROUND` half-away-from-zero arithmetic. Usage kind `DECODE` labels
are `api`, `storage`, `compute`, with `UNKNOWN` as the default.

The Oracle audit-log write is suppressed: U7 owns `billing_audit_log`. The
service retains an audit sink seam with the source message strings. The
Mongo-backed `subscriptions` read path is unexercised until U3 lands; tests use
the static subscription seam.

`sp_finalize_rating` preserves the source's natural-key collision and foreign-key
behavior: an imported period with a non-derived id is updated by
`(tenant_id, period_start)`, then the absent derived period id raises the mirrored
`fk_rr_period` violation inside the transaction, so no result is persisted.

Recon for this unit is a child self-check (`run_mode=fixture`): the harness runs against
the deterministic read-only `NS=demo` Oracle fixture. The CLI exposes that as
`--mode live` (its modes are `live`, `snapshot`, `continuous`), which is what the U0-U2
wrappers use as well. The parent owns the independent live gate.
Stored-procedure parity is evidenced by replaying the recorded Oracle transcripts in
`procs/oracle/transcripts/rating/*.json` against the migrated service.
