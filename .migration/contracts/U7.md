## PKG_OW_UTIL conversion (interface contract)

Ported to `services/legacy-billing/app/ow_util.py`, the same application that U1/U2
ported `reports.py` in. The package's mutable globals (`g_call_count`, `g_last_module`,
`g_last_uuid`) become instance state on `OwUtil`, i.e. scoped to one caller instead of
one Oracle session — the source never resets them and no caller reads another session's
copy, so no behaviour depends on the wider scope.

| Source | Port | Semantics preserved |
|---|---|---|
| `f_md5_uuid` | `md5_uuid(value)` | MD5 over the input's UTF-8 bytes (`UTL_RAW.CAST_TO_RAW` on an AL32UTF8 database), lowercase hex, hyphenated 8-4-4-4-12; `call_count` incremented and `last_uuid` set exactly as the source does |
| `f_code_desc` | `code_desc(db, code_type, code_val)` | single-document equality lookup on `codes` (`_id = "<code_type>#<code_val>"`, U0's composed key); no match → `UNKNOWN(<TO_CHAR(NVL(val,-1))>)`; a matched row with a NULL description returns null. The dynamic-SQL `EXECUTE IMMEDIATE` wrapper is dropped: the statement was static |
| `f_dt2str` | `dt2str(value)` | `TO_CHAR(dt,'DD-MON-YY','NLS_DATE_LANGUAGE=ENGLISH')`: zero-padded day, uppercase 3-letter English month from an in-code table (never a locale-dependent `%b`), 2-digit year; NULL → null |
| `f_str2dt` | `str2dt(text)` | `TO_DATE(str,'DD-MON-YY','NLS_DATE_LANGUAGE=ENGLISH')` including Oracle's `YY` current-century pivot; every unparseable value returns null silently, mirroring `WHEN OTHERS THEN NULL` — dirty dates stay silently null, they are not repaired |
| `log_msg` | `OwUtil.log_msg(module, message)` | see below |

Both directions are pinned to a recorded Oracle transcript
(`.migration/recon/U7/util_transcript.json`, captured read-only from the NS=demo fixture
by `scripts/tp_mongo/verify_u7.py transcript`) and replayed against the port, so the
conversion is evidenced against the source's real output, not against a reading of it.

### `log_msg` — AUTONOMOUS TRANSACTION semantics

The source is `PRAGMA AUTONOMOUS_TRANSACTION`: the audit row is inserted and committed in
a transaction of its own, so it survives a caller rollback, and a logging failure is
swallowed (`WHEN OTHERS THEN ROLLBACK`) so the caller is never told. The port preserves
all four properties:

1. **Unconditional.** Every call attempts the write; there is no level/filter switch.
2. **Independent.** The write never joins a caller's transaction: `log_msg` accepts no
   `ClientSession` and passes none, and it writes through a collection handle carrying its
   own write concern (`majority`) instead of inheriting the caller's. A single-document
   insert is atomic, which is the `COMMIT` equivalent.
3. **Truncating, not rejecting.** `module` is cut to 30 characters and `message` to 4000,
   echoing `SUBSTR(...,1,30)` / `SUBSTR(...,1,4000)`; `last_module` is set before the
   write is attempted, as in the source. This is deliberately wider than the source — see
   the divergence below.
4. **Silent on failure.** No failure of the logging operation propagates — argument,
   encoding and driver errors all return `False`, matching the source's `WHEN OTHERS`,
   which wraps the whole procedure body rather than the INSERT alone.

#### Declared divergence: audit acceptance is wider than the source

`g_last_module` is declared `VARCHAR2(30)` and the estate runs `NLS_LENGTH_SEMANTICS=BYTE`
on `AL32UTF8` (`BILLING_AUDIT_LOG.MODULE` is `VARCHAR2(30 BYTE)`). `g_last_module :=
p_module` therefore raises `ORA-06502 (character string buffer too small)` *before* the
INSERT for any module over 30 bytes — read-only probes confirm both 40 ASCII characters and
30 `ö` characters (60 bytes) raise (`.migration/recon/U7/audit_acceptance_probe.json`) —
and `WHEN OTHERS THEN ROLLBACK` then drops the event silently, leaving `g_last_module`
unchanged; the INSERT's `SUBSTR(p_module,1,30)` is unreachable for those calls. A message
truncated to 4000 characters can similarly exceed the 4000-byte column and lose the event.

The port does not reproduce that loss. The unit spec requires an unconditional audit write,
the Mongo target has no byte ceiling, and truncation is by characters, so events the legacy
logger silently discarded are recorded and `last_module` is always set. Audit coverage is
strictly wider than the source; no event the source kept is changed.

`logged_at` is written as the current UTC time truncated to whole seconds — the source
column is an Oracle `DATE` defaulted from `SYSDATE`, which has no sub-second component.

## Load protocol

Idempotent by construction: every run drops and recreates `billing_audit_log` before
inserting the migrated rows and rebuilding the TTL index (engagement convention,
05_decisions.md — M0 cannot make a multi-collection rename swap atomic). The extract is a
single serialized Oracle read (source-load cap 1). Oracle is read-only: U7 never calls
`pkg_ow_util.log_msg` on the source, since that procedure writes.

## Recon gate

`recon run --unit U7 --family oracle --mode live --seed 0` over `billing_audit_log`, with
the mapping subset rendered verbatim from the approved spec. `result.json` is the only
merge authority. Child runs are `run_mode: fixture` self-checks against this VM's own
deterministic NS=demo fixture; the parent's uncontended run is the live proof. Tier 3 is a
full keyed diff (0 roots, far below the 100,000 threshold) — an empty population is graded
by tiers 1-3, and that is the whole grade the migrated data can carry.

## Declared-unexercised / open risks (top of the PR body too)

- **`BILLING_AUDIT_LOG` is empty at source (0 rows).** The collection is created and
  graded empty: root count 0 = 0, aggregates over an empty population, keyed diff over an
  empty key set. No migrated document exercises the `LOGGED_AT`/`MODULE`/`MESSAGE`
  transforms, and recon cannot grade a population that does not exist. The write path
  replacing `log_msg` is evidenced by unit tests plus the unit-owned probes below, never
  by the harness verdict.
- **TTL expiry** is evidenced by the index specification (`expireAfterSeconds = 7776000`
  on `logged_at`) and by a probe that inserts a deliberately over-age document and waits
  for the background sweep. If the sweep does not fire inside the probe window the probe
  records that outcome verbatim and the expiry stays declared-unexercised — it is never
  reported as observed.
- **Harness Tier 4** (app-level parity replay) is not reachable from the `recon` CLI: the
  engine requires `run_source`/`run_target` callbacks the CLI does not expose. The
  PKG_OW_UTIL conversion is therefore evidenced by the unit-owned Oracle-vs-port transcript
  replay (`scripts/tp_mongo/verify_u7.py`), declared as unit evidence and NOT as a harness
  verdict.
- **Fixture-only run mode.** All U7 recon runs here are `run_mode: fixture`; the wave gate
  runs LIVE independently.
