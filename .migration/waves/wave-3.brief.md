Skill feedback to fold in before the next wave:
- Oracle foreign keys must be read from ALL_CONSTRAINTS and reproduced as part of the unit: data parity passes with a constraint missing, so tier 3 will not catch it. Put constraint DDL in a pg_constraint-guarded DO block so the unit stays idempotent.
- Retyping a timestamptz column in place must convert explicitly (USING col AT TIME ZONE 'UTC') and be guarded on the column still being timestamptz: a bare ALTER reads the stored instant in the migrating session's zone, and the guarded form is the only one safe to re-run, because the USING expression flips meaning once the column is zone-less.
- A package that reads a table row-at-a-time cannot be converted while that table lives only on the other track. Route it to the parent as a track-split question instead of materialising a copy inside the package's unit.
- Proving a converted package writes the audit log does not need a committed run: call the procedures inside a transaction, capture the rows, roll back, and the reconciled rows on a shared branch are undisturbed.
- Never drop log_msg to satisfy a manifest that does not declare billing.billing_audit_log — the declaration is the fix, the behaviour is the contract.
- A wave-0 DDL correction applied from a wave-3 unit branch breaks the ownership model even when the parent asked for it; fold it into the parent-owned schema change instead.
- Owner-directed corrections push a unit past the nominal three-full-run / one-live-read cap; report the overrun rather than trimming the evidence to fit it.
